# PRD: 字体预览生成器 (font-preview)

## 概述
一个 CLI 工具，输入字体文件（.ttf/.otf），输出一个美观的 HTML 预览页面，展示字体的全貌。方便设计师和开发者快速查看字体效果。

## 功能点

### 1. 基础命令
- `font-preview <字体文件路径>` — 生成预览 HTML
- `font-preview <字体文件路径> -o output.html` — 指定输出路径
- `font-preview --help` — 显示帮助信息

### 2. 预览内容
预览 HTML 页面需包含以下内容：

- **字体元信息**：字体名称、样式（Regular/Bold/Italic 等）、版本、制造商、设计师、版权信息
- **字符集展示**：按 Unicode 区块分组展示所有字符（至少 Latin、CJK、标点符号等），每个字符显示其 glyph 和 Unicode 编码
- **文本预览区**：可自定义输入文字实时预览（用 input 框），并展示多段预设示例文本（英文 pangram + 中文示例）
- **字体规格**：展示关键指标：ascender、descender、unitsPerEm、glyph count
- **字号切换**：提供 12px ~ 72px 的字号滑块或按钮，所见即所得
- **深色/浅色模式切换**
- **页面响应式**：在手机和桌面都能友好显示

### 3. 技术实现
- 使用 Python 脚本实现（依赖 fonttools 库解析字体）
- HTML 页面为单文件自包含（所有样式和脚本内嵌），方便分享
- 字体通过 base64 内嵌到 HTML 中显示（用 @font-face）

### 4. 输出
- 生成的 HTML 文件用浏览器打开即可看到完整的字体预览
- 文件体积应尽量优化（内嵌字体可压缩）

## 验收标准
- [ ] 运行 `font-preview test.ttf` 生成 test.ttf.html，浏览器打开页面完整展示
- [ ] CJK 和 Latin 字符都能正确渲染
- [ ] 所有交互功能（字号切换、暗色模式、自定义文本）正常工作
- [ ] 以输出文件名 + 时间戳确认每次生成是独立的
- [ ] `--help` 输出完整的参数说明

## 范围外
- 不做 Web 服务（只用 CLI）
- 不做字体编辑/转换
- 不做批量处理
- 不做 PDF/图片输出（只出 HTML）
